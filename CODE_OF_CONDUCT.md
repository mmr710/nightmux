# Code of conduct

nightmux follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be kind, assume good faith, critique code rather than people, and keep
discussion on topic. Harassment of any kind is not tolerated.

Report a problem privately to the maintainer through
[a private security advisory](https://github.com/mmr710/nightmux/security/advisories/new)
(it reaches only the maintainer) or by Telegram DM to the maintainer in the
[community group](https://t.me/+SGmmExdMHTQ3OWVk). Reports are kept confidential.
