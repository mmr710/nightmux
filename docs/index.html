Why vibe coders run it

🌙A limit no longer ends the night

Claude Code runs out of its 5-hour window at 2:14 AM. nightmux keeps your queue and the cut-off turn, and sends them back the moment the window resets. Can't wait? !failover codex hands the work over now.

📱Your phone is the terminal

One Telegram topic (or dashboard chat) per project, one tmux session behind it. Menus become buttons, so a "yes" is one tap from bed. Photos, files and voice notes go straight to the agent.

✅It keeps going until the tests pass

!goal npm test runs your check after every turn and sends the failures back. It stops and asks when it goes in circles.

🗓Plan the whole night

!shift takes one prompt per line and runs them in order. !at 03:00 and !every 4h start work while you sleep.

🏁Race two agents, keep the best

!race claude,codex runs the same task in two worktrees. Pick the winner with one tap.

☀️Wake up to a briefing

What got done overnight, which PRs are ready, which errors came in, and a GIF of the night.

💸Fewer tokens spent

Live context %, the limit windows, auto-compact, a fresh session per task, a prompt coach that catches vague prompts, and !stats says what to change.

🔒Yours, entirely

Python standard library only, zero dependencies, on your machine with your keys. Nothing is exposed by default. MIT licensed.

Every agent you already use

One topic, a bench of agents. Switch with !codex, ask one without switching with @agy, hand a stuck task to another with !failover.

Install

curl -fsSL https://raw.githubusercontent.com/mmr710/nightmux/main/install.sh | sh
  • Just looking? python3 nightmux.py --demo — no bot, no keys.
  • No Telegram? nightmux up starts the dashboard on 127.0.0.1; a bot can be added later.
  • Docker: docker run -it -v ~/code:/code -p 127.0.0.1:9090:9090 ghcr.io/mmr710/nightmux
  • Linux or macOS with tmux and Python 3.8+. Read SECURITY.md before you add a second person or machine.
