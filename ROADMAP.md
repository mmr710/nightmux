# Roadmap

What is planned, roughly in order. Want one of these sooner, or have a better idea?
Open an [issue](https://github.com/mmr710/nightmux/issues/new/choose) — and say if you'd
like to build it.

## Next

- **`!upgrade`** — update nightmux on this machine and every peer from Telegram, restart, report versions.
- **Live terminal on the web** — the session's full scrollback in the dashboard, read-only by default.
- **Discord and Slack** — the same topics-to-sessions model on a Discord forum channel or Slack channels.
- **MCP server** — let any MCP client list sessions, read output and queue prompts.
- **GitHub trigger** — comment `/nightmux fix` on an issue or PR and a topic picks it up.

## Later

- **Night replay** — scrub through last night in the office, turn by turn.
- **Budgets** — a per-project token or dollar cap that pauses the queue when hit.
- **Arena board** — `!race` results over time: which agent wins which kind of task.
- **Relay** — one agent writes the plan, another implements, a third reviews, as one pipeline.
- **Team mode** — roles (watch / prompt / admin) and an audit log, for a shared box.
- **Smart lights** — a Home Assistant / Hue hook: amber when an agent needs you, green when the night's done.
- **Voice briefing** — the morning summary as a voice note.
- **Office skins** — themes and avatars for the pixel office.
